Manim Animation Generator

Generate mathematical animations using natural language queries

About This Project

The Manim Animation Generator is a web-based application that creates mathematical animations using Manim through natural language queries. This tool connects to an n8n webhook to convert user requests into Manim code, which is then executed to create animations.

Important Notice

This GitHub Pages site is a static landing page only. The actual application requires server-side processing and cannot run on GitHub Pages.

How It Works

  1. Enter a description of the animation you want to create
  2. The application sends your request to an n8n webhook
  3. n8n processes the request and generates appropriate Manim code
  4. The generated code is executed to create the animation
  5. View the generated animation in your browser

Deployment Options

To use this application, you need to deploy it to a platform that supports Python applications:

Option 1: Render (Recommended)

  1. Fork this repository
  2. Create an account at render.com
  3. Create a new Web Service
  4. Connect it to your forked repository
  5. Set the build command to: pip install -r requirements.txt
  6. Set the start command to: gunicorn app:app
  7. Deploy!

Option 2: Heroku

  1. Fork this repository
  2. Create an account at heroku.com
  3. Install the Heroku CLI
  4. Clone your forked repository
  5. Run: heroku create
  6. Run: git push heroku main

Option 3: Docker

If you have Docker installed:

docker build -t manim-animation-generator .
docker run -p 5000:5000 manim-animation-generator

Then visit http://localhost:5000
